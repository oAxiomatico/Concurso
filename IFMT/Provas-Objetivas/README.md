Este diretório organiza os cadernos históricos de concursos efetivos de Professor EBTT — área Matemática. Os documentos são materiais oficiais do IFMT. Nesta sessão, os **PDFs puderam ser identificados nos servidores oficiais**, mas o serviço de download de bytes não permitiu copiá-los para o GitHub. Por isso, preservamos os **links diretos dos PDFs originais** abaixo, sem fingir que os PDFs foram incorporados ao repositório. Os links abrem o arquivo oficial completo.
